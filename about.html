ChemIsFree is a community-oriented index of software, web tools, libraries, databases, and other resources relevant to chemistry and drug discovery.

It is organised around research tasks, so people can start from what they need to accomplish instead of already knowing which package to search for.

01 / ACCESS

Free access comes first.

The catalogue aims to include no-cost resources and openly licensed software or data. A free website is not automatically open-source, and an open-source project can have separate dependencies or hosted services with different terms. Check the individual entry and upstream terms before relying on it.

02 / PROVENANCE

Source links matter.

Entries link to official websites and source repositories where the registry provides them. Imported records keep a provenance label and are not presented as individually tested or independently verified by ChemIsFree.

Some catalogue metadata has been normalised from the public Assayer project. Only entries with an explicit free/open licence or no-cost access label were considered for import. Unknown, restricted, academic-only, commercial, and proprietary labels were excluded.
