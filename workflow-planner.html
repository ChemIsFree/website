HOW THE PLAN IS BUILT

Transparent
by design.

The planner matches workflow steps to catalogue tasks, then ranks options using your interface, operating-system, compute, and access preferences. It does not claim that tools with similar tags are interoperable or that a suggested route is a validated protocol.

Some catalogue entries are imported from other public registries and are marked as not independently reviewed by ChemIsFree. Check the official resource, licence, citations, version, and compatibility before relying on it in research.
